Cài Đặt Userscript MangaDex

Đọc truyện trực tiếp trên website MangaDex: Bản dịch tiếng Việt sẽ tự động đè khít lên bong bóng thoại ngay khi bạn đọc từng trang.

Quy trình cài đặt nhanh:

  1. Cài đặt tiện ích mở rộng Tampermonkey trên trình duyệt của bạn (Chrome, Edge, Firefox, Brave).
  2. Nhấp vào liên kết cài đặt trực tiếp bên dưới:
    Cài Đặt Userscript (1-Click)
  3. Tampermonkey sẽ tự động mở tab xác nhận ➔ Bấm Install (Cài đặt) là hoàn tất.
  4. Truy cập bất kỳ truyện nào trên MangaDex (ví dụ: mangadex.org/chapter/...), thanh điều khiển sẽ tự động xuất hiện.

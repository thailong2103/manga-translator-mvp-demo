# MangaDex AI Translator Overlay

Hiển thị bản dịch tiếng Việt đè lên bong bóng thoại MangaDex bằng AI.
Hỗ trợ 2 Pipeline linh hoạt (Manga-OCR Text và Multimodal Vision AI), dịch qua Google Translate hoặc LLM, chống nghẽn đơ tab 100%, tự co giãn theo tranh vẽ.

Vui lòng đọc file [HUONG_DAN_SU_DUNG.md](HUONG_DAN_SU_DUNG.md) để biết cách cài đặt và sử dụng.
Chi tiết về nguyên lý hoạt động có trong file [KIEN_TRUC_VA_NGUYEN_LY_HOAT_DONG.md](KIEN_TRUC_VA_NGUYEN_LY_HOAT_DONG.md).
